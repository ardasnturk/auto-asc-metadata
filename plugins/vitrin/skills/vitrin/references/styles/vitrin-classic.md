# Vitrin Classic (`vitrin-classic`)

> Vitrin's own preset (the original look, upgraded to the composition rules of [art-direction.md](../art-direction.md)).

Confident and colorful: a deep indigo night with brand blooms low behind the device, a bold rounded grotesk and one warm accent word. Works for almost any app; the default for old art-direction files.

```json
{ "preset": "vitrin-classic", "brand": { "primary": "#…", "secondary": "#…" } }
```

## Palette (as rendered)

| Token | Value |
|---|---|
| Background | `#120F2E` → `#3A2C9C`, brand blooms (`#7B6CFF`, `#E2557A`) kept low so the headline sits on the dark stop |
| Headline | `#FFFFFF` |
| Kicker / sub | `#D9D4FF` |
| Emphasis | coral `#FF8A6B` (brand-tinted, ≥ 4.5:1) |
| Inverted | lavender paper `#F7F4FF` with ink `#1B1640` |

## Typography

Plus Jakarta Sans 800, ~0.128 × canvas width, tracking −0.035em, leading 1.0, centred. Body Inter.

## Headline emphasis

Color only: the `*word*` in the accent.

## Background and decoration

Vertical gradient from the darkest stop, three blurred blooms (brand colors) behind the device, a soft accent ribbon, two sparkles near the device. Grain 3.5 %. Density: editorial.

## Device and framing

Graphite frame, tinted soft shadow. Rhythm: bleed-bottom → offset → bleed-bottom → tilted (±8°) → two-devices → bleed-top.

## Copy tone

Plain and warm. Outcome first, 3–5 words: "Keep your *streak* alive", "Progress you can *see*".

## Avoid

Putting the emphasis on a pale brand tint; more than one accent word.
